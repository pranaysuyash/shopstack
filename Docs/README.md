# Docs Folder

This repository keeps historical design docs and context files out of Git tracking to keep PRs focused on code and runtime behavior.

The active runtime truth remains in source code under `shopstack/` and `app.py`.

For historical planning context, keep files in your local workspace copy of `Docs/` as needed.

## Local housekeeping

- `Docs/local-cleanup-policy.md` documents the local cleanup cron script, Codex cleanup automation, protected paths, and the cleanup actions taken in this session.
